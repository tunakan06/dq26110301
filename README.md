# キリノシマ物語 〜きりに きえた しまじま〜

スマホのブラウザで遊べる、オリジナルの見下ろし型RPGです（HTML5 / 依存ライブラリなし）。

## あそびかた
- `index.html` をブラウザで開くだけ（GitHub Pages でもそのまま動きます）
- 画面下の十字キーで移動、**A**＝はなす・しらべる・けってい、**B**＝メニュー・もどる
- PCではキーボード（矢印キー / Z=A / X=B）でも操作できます
- 宿屋に泊まるか、メニューの「セーブ」で記録（ブラウザに保存）

## ストーリー
霧に沈んだ島々を、ボスが守る「ほしのかけら」を集めて村の祭壇に捧げ、
ひとつずつ取り戻していく冒険。仲間（リナ・ガント）が途中で加わります。

## ファイル
- `js/data.js` じゅもん・キャラ・どうぐ・モンスター・ダンジョンのデータ
- `js/core.js` 状態／セーブ・効果音・入力・メッセージ／メニュー
- `js/field.js` マップ生成・描画・移動・町の人・イベント
- `js/battle.js` ターン制バトルと敵グラフィック
- `js/main.js` タイトルとメインループ
